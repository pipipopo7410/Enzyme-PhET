# 酵素實驗室 2.3

國中生物互動教學網站。單檔 `index.html`，不依賴外部套件、圖片或網路 API。

## GitHub Pages 上傳

1. 解壓縮 ZIP。
2. 在原本測試用的 GitHub Repository 根目錄上傳 `index.html`、`README.md`、`CHANGELOG.md`、`TEST_CHECKLIST.md`（覆蓋同名檔案）。
3. Settings → Pages 選 main 分支根目錄，開啟測試網址。
4. 建議用 iPad Safari 橫向測試；直向也可使用，狹窄裝置有設定／模擬／圖表切換。

## 核心功能

- 自由探索／雙組對照實驗。
- 三種受質與相應酵素；選錯酵素不會有反應。
- 可選 1 倍／2 倍受質量和酵素量；實驗開始後鎖定這些選項，仍可即時調整溫度與 pH。
- 受質、產物、酵素相對活性三張同步折線圖。
- 模擬上限 30 秒，標準最佳條件約 25 秒完成。模擬數值非實測。
- 分子動畫示意酵素專一性：受質接近缺口、暫時結合、產物離開；動畫事件根據實際模型產物增量觸發，並非逐一追蹤真實分子。
- pH 0–7–14：燒杯水色從紅經中性漸層至藍。

## 科學概念說明

- 唾液澱粉酶產物採「較小的醣類」；胃蛋白酶產物採「較短的胺基酸鏈」，不代表直接生成葡萄糖或游離胺基酸。
- 氨轉尿素是肝臟內多種酵素參與的反應途徑，本網站僅做跨單元的概念示意。
- 各反應速率、溫度影響與相對量為簡化教學模型，不能當作真實定量實驗結果。
