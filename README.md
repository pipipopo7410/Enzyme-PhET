# 酵素實驗室 2.2 — GitHub Pages 上傳版

這是單檔 HTML 教學網站，無須建立專案或安裝套件。

## 上傳

1. 將本 ZIP 解壓縮。
2. 到測試用 GitHub Repository → Add file → Upload files，選取 `index.html`、`README.md`、`CHANGELOG.md`、`TEST_CHECKLIST.md`。
3. 若是第一次開新 Repository，在 Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save。
4. 網址通常是 `https://<帳號>.github.io/<Repository名稱>/`。請先用測試站試操作，不要直接覆蓋既有 1.0 正式站。
5. 若網站還顯示舊版，使用瀏覽器重新整理並核對畫面左上角版本「2.2」。

## 2.2 核心操作

- 「自由探索」可複選最多兩組受質與酵素。
- 「雙組對照實驗」先選擇操作變因；A、B 組只設定不同的操作變因，其他列在「控制變因」並同步設定。
- 「開始」後鎖定受質／酵素種類與數量、操作變因種類、兩種模式切換；**溫度與 pH 仍可即時拉動**，包含暫停後。
- 模擬時間從 0 跑至 **30 秒**自動停止。模擬速度約 1.8 倍真實鐘錶速度，不等於實驗室中的真實秒數。
- 在簡化模型下，**1 倍受質、1 倍酵素、37°C 與該酵素設定的最適 pH** 時，受質在模擬第 25 秒用完。2 倍酵素可更快完成；其他條件以相對活性影響反應進度。
- 重新開始可清空前一次反應記錄，同時保留當前設定，並重新開放受質／酵素／數量選取。

## 科學說明

- 澱粉經唾液澱粉酶作用，產生較小的醣類；蛋白質經胃蛋白酶作用，產生較短的胺基酸鏈。
- 「氨 → 尿素」為肝臟內多種酵素共同參與的反應之**高度簡化示意**，不是單一酵素一步完成。
- 三種受質使用圓形（澱）、三角形（蛋）、方形（氨）；對應酵素具有相同形狀的凹口。產物用同色系淺色的醣、胺、尿素區分。
- 高溫失活、溫度與 pH 最適範圍都是為比較趨勢建立的教學模型，**非實測數據，也不是所有酵素具有固定 25 秒反應時長**。
- 圖表中的數量為相對單位，酵素「相對活性」不等於「酵素總量」或「產物量」。
