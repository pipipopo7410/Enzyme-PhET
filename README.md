# 酵素實驗室 2.0｜全版操作優化版

這是「酵素實驗室 2.0」的操作優化測試版，保留自由探索與雙組對照實驗。

## 更新的五項重點

1. 全版鎖定：網頁、左側控制、圖表區全部不使用垂直或水平捲動。iPad 橫向直接顯示三欄；iPad 直向將三張圖排列在下方；窄螢幕以「設定／模擬／圖表」切換，仍不捲動。
2. 燒杯外形：單組自由探索的燒杯加寬，接近常見實驗燒杯；雙組仍以並排示意保持比較清楚。
3. 粒子動畫：由重複建立 SVG 改為單一 Canvas 每畫格更新，圖表以較低頻率更新，以減少跳格感。是否達到理想流暢度仍需 iPad 實測。
4. 自動停止：反應轉化程度達到示意門檻，或模擬時間到達上限後停止；學生可按「繼續」再觀察。圖表橫軸保留從 0 開始的完整歷程，不滑動裁掉早期趨勢。
5. 減少文字：僅保留必要的控制項名稱、組別、受質／產物數量及三種圖表名稱。科學模型說明放在右上角「？」。

## 既有功能保留

- 自由探索：受質、酵素選擇，溫度、pH、受質量、酵素量可在模擬進行時即時調整。
- 雙組對照：選擇操作變因，各自設定 A 組與 B 組；其他條件同步，兩組曲線同圖呈現。
- 三種折線圖：受質剩餘量、產物累積量、酵素相對活性。
- 課程表述：澱粉變為較小的醣類；蛋白質變為較短的胺基酸鏈；氨變尿素為肝臟多種酵素的整體轉換模型。

## 上傳 GitHub Pages

1. 建議先上傳至新的測試儲存庫，避免覆寫正式課堂網站。
2. 解壓縮 ZIP，將 `index.html` 放在儲存庫根目錄；README、更新紀錄與檢核表可一併上傳。
3. 在儲存庫 Settings → Pages 設定 main branch、/(root) 發布。
4. 開啟發布後的網址，依 `TEST_CHECKLIST.md` 使用校用 iPad 驗收。

## 科學模型界線

此網站以國中酵素概念和圖表判讀為目標，所有數值為示意模型並非實測。粒子動畫展示運動趨勢，**不是**逐次模擬分子實際碰撞後的化學反應。溫度與 pH 的活性曲線、反應時間及失活公式均屬簡化設計。肝臟轉換氨為尿素是多步驟反應，非單一酵素直接催化。

## 相容性

整站僅有一個 HTML 檔案，沒有第三方 CDN 依賴。已使用 Chromium 模擬 1024×768、768×1024、390×844、844×390 的全版布局，並做程式語法與基本反應邏輯檢測。**未**完成真實 iPad Safari、投影設備及連續長時間效能驗收。
