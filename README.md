# 酵素實驗室 2.6｜GitHub 上傳包

這是一個單檔 HTML 教學模擬器，不依賴外部 JavaScript 套件。

## 部署
1. 解壓縮 `Enzyme-Lab-2.6-GitHub.zip`。
2. 將全部 4 個檔案放到 GitHub Repository 根目錄，包含 `index.html`。
3. 在 **Settings → Pages** 選擇 `Deploy from a branch`、`main`、`/(root)`。
4. 開啟 GitHub Pages 網址，確認檔案已更新。

## 結構
- `index.html` — 全站程式
- `README.md` — 上傳說明
- `CHANGELOG.md` — 修改紀錄
- `TEST_CHECKLIST.md` — 實機測試清單

本版本從 2.5 修改，不需更動原網站以外的檔案。正式站上線前，建議先在測試 Repository 驗收。
