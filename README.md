# 酵素實驗室 2.4｜連續碰撞反應版

## GitHub Pages 上傳
1. 解壓縮 `Enzyme-Lab-2.4-GitHub.zip`。
2. 將解壓後的 `index.html`、`README.md`、`CHANGELOG.md`、`TEST_CHECKLIST.md` 全部上傳到 GitHub Repository 根目錄（**不要**連同 ZIP 或外層資料夾一起上傳）。
3. 在 Repository 的 **Settings → Pages** 選擇 `Deploy from a branch`，分支 `main`、資料夾 `/(root)`。
4. 部署更新後重新整理網頁；若仍看到舊版，可使用私人瀏覽分頁重新開啟測試網址。

## 功能與原則
- 保留自由探索、雙組對照、三張即時圖表、30 秒模擬時間與最佳條件下約 25 秒完成。
- 反應開始後仍可隨時調整溫度與 pH；反應進行中受質、酵素、數量與模式選擇鎖定。
- **反應結束**後自動解除上述鎖定。換選擇即準備下一次實驗，不需要事先點重新開始。
- 粒子具有持續保存的位置與速度，不再由溫度 × 時間的公式重新推算位置。
- 受質在燒杯內靠近相容酵素時，才進入靠近缺口、短暫結合、局部釋放產物的動畫；產物從原位置出發，不會由燒杯外飛入。
- 仍使用國中教學用的**簡化模型**：圖表為相對反應量、粒子是一群分子的圖示，不是實測數據或真正的分子動力學。
- 使用原生 HTML/CSS/JavaScript Canvas/SVG，無需外部 CDN。
- 全站所有畫面禁止垂直或水平整頁捲動；較小螢幕使用設定／模擬／圖表切換。
