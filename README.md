# 酵素實驗室 2.0｜獨立測試版

此版本以既有「酵素模擬實驗」的教學功能為依據，重新整理前端畫面與反應模型，保留自由探索的核心，新增雙組對照實驗。**本包不會自動更新原有 GitHub 網站。**

## 如何發布到 GitHub Pages

1. **先保留原網站**。最穩妥的方法是到 GitHub 建立新的公開儲存庫，例如 `enzyme-lab-v2-test`，用來放測試版；或先在原儲存庫另開測試分支。
2. 解壓縮本 ZIP，選取其中 `index.html`（可一併上傳這份 README、CHANGELOG、TEST_CHECKLIST），在新儲存庫選 **Add file → Upload files → Commit changes**。ZIP 不能直接當成網站上傳，必須先解壓縮。
3. 進入儲存庫 **Settings → Pages**，選擇 **Deploy from a branch**、`main`、`/(root)`，儲存。
4. 等 GitHub Pages 顯示網站網址後，使用 iPad Safari 開啟測試。網址通常為 `https://你的帳號.github.io/儲存庫名稱/`。
5. 測試完成且確認滿意後，再決定是否把新 `index.html` 套用到原本的正式網站。**不要在尚未確認前覆蓋原版。**

## 主要功能

- **自由探索**：可選擇最多兩種受質和最多兩種酵素，隨時調整溫度、pH、酵素量與受質量。受質或酵素選擇改變時，圖表會開始記錄目前新組合的資料；原有反應進度不重置。
- **雙組比較**：同時比較 A 對照組、B 實驗組；可選擇 `溫度 / pH / 酵素量 / 受質量` 其中之一分開調整，其餘參數同步改變。
- **三張圖**：受質剩餘量、產物累積量、酵素相對活性。A 組實線、B 組虛線；橫軸為模擬時間，縱軸使用相對單位。
- **即時調整**：反應進行中不鎖定控制項。中途修改條件會改變此後的反應，且歷史曲線保留；若要取得便於比較的標準雙組曲線，請先設定條件，再按「重新開始」。
- **單檔 HTML**：不依賴 Tailwind、Chart.js 或線上圖片，開發成果都在 `index.html` 中。

## 科學模型及界限（教師閱讀）

1. **相對數量**：表中數字是演算用相對單位，不代表分子數、真實摩爾數或測量值。
2. **反應速率**：採用受質量、酵素量、環境活性因子決定的簡化飽和速率模型。沒有宣稱可套用於任何特定人體酵素的精確反應速率。
3. **溫度**：以常見人體酵素的教學情境呈現接近體溫活性佳、高溫活性下降、持續高溫可能造成結構受損的趨勢；不是所有酵素通用的精確熱變性門檻。冷卻後不會自動修復模型中累積的失活。
4. **pH**：以中性較適合唾液澱粉酶及肝臟酵素系統、酸性較適合胃蛋白酶作為基本模型；非真實實測曲線。
5. **消化產物**：澱粉 → 較小的醣類；蛋白質 → 較短的胺基酸鏈。單一酵素反應不直接代表全程消化成單醣或游離胺基酸。
6. **氨變尿素**：顯示肝臟內**多種酵素參與的一連串反應**的整體結果，簡化省略多個中間產物、額外反應物與能量需求，不能把它當成氨直接接觸一個酵素就變成尿素。
7. **微觀粒子**：形狀、移動、數量都是教育示意，不是按分子實際比例繪圖。粒子數量根據模型反應進度更新，不代表模擬真實的化學鍵斷裂與分子動力學。
8. **倍數**：受質量在固定體積下採 1 倍 / 2 倍。反應中切換等同於立即加入或移除尚未反應的受質；酵素量切換等同於改變可用酵素數量。
9. **活性圖**：代表酵素當下相對活性，**不是**酵素數量，也不是當下整體反應速率。即使兩組相對活性一樣，酵素量不同仍可能導致不同反應速度。

## 尚待 iPad 實測

- 校用 iPad Safari：觸控調整、快速切換模式、橫直向變換、投影辨識度。
- 長時間執行、背景切換、數據在各種極端參數下的表現。
- GitHub Pages 的跨網站/多頁導覽與離線重開。**單檔沒有外部執行依賴，不代表 GitHub Pages 自動具有可靠的離線快取功能**；真正離線部署需另設計與驗收 PWA/Service Worker。

本版為第一輪可操作原型，建議先用 10～15 分鐘示範及學生自由操作，之後按實測結果決定要不要調整介面資訊量、曲線呈現與模型。
