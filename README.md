# 酵素實驗室 2.7｜GitHub 上傳版

這是 2.6 的完整接續版本，**不是單獨的補丁**。部署時將本 ZIP 解壓縮，把所有檔案放在 GitHub Repository 的根目錄（`index.html` 必須在根目錄），使用 GitHub Pages 開啟網站即可。

## 本版保留

- 單組自由探索與雙組對照實驗
- 三種受質／三種酵素的圖形、配色及專一性
- 胃蛋白酶與三角蛋白質的貼合形狀
- 肝酵素雙缺口、兩個氨結合、一個較大的尿素產物的概念動畫
- 實驗中可隨時調整溫度與 pH；反應開始後暫不修改受質、酵素及數量
- 模擬最長 30 秒，以及固定全版布局

## 2.7 核心修正

右側的「受質剩餘量／產物累積量」改由連續反應進度計算，不再每一顆圖示消失就跳動固定數值。中央動畫仍為帶有個別位置、速度的代表性粒子，會靠近、吸附、分離。動畫轉換會參照相同反應進度提前進入吸附階段；直到連續數值進度足夠才完成分離。最後的受質若尚未完成結合，圖表暫時保留極少量餘額，避免出現「圖表 0、燒杯還有受質」的矛盾。

**教學模型說明：** 中央圖示代表許多分子的可視化樣本，右側是巨觀的相對數量，不是逐顆實際分子計數；氨→尿素的雙氨動畫是跨單元概念示意，不代表尿素循環完整化學方程式。
